# M8TP GTA Map — الإصدار 2

مشروع آيفون مستقل بواجهة SwiftUI ومحرك خريطة UIKit، يدعم iOS 17+ وآيفون وآيباد. الواجهة إنجليزية. هذا الإصدار يوسّع المشروع الأول ويزيل المساحات السوداء الكبيرة حول عرض الخريطة.

## ما تغير

- خريطة تملأ الشاشة، شريط بحث عائم، وأزرار ولوحات SwiftUI للأقسام والمواقع والمسار والمفضلة والبيانات.
- 933 موقعًا من مصدر مجتمعي في 38 قسمًا يحتوي بيانات فعلية، منها 54 ورقة لعب، 100 مجسم، 50 جهاز تشويش و100 منتج LD Organics.
- خريطة satellite مطابقة لنظام إحداثيات المصدر، مضمنة للعمل دون إنترنت. البيانات ليست نسخة كاملة من GTAWeb ولم يتم اختبار جميع المواقع داخل اللعبة.
- تجميع العلامات المتقاربة، البحث، إظهار/إخفاء الأقسام والمكتمل والمفضلة، وحفظ التقدم المحلي.
- عدادات لكل قسم، معلومات القسم، تحديد القسم كله كمكتمل وإعادة ضبط قسم منفرد بعد التأكيد.
- روابط صور لـ290 موقعًا، تُحمّل من مزودها الأصلي عند فتح البطاقة. قد يفشل الرابط أو يحتاج إنترنت. يوجد رابط مصدر/دليل لكل موقع؛ لا يتم نسخ شروحات HTML الأصلية.
- إضافة محطات مسار يدويًا أو ترتيب المرئي غير المكتمل حسب الأقرب، واستثناء أقسام من التخطيط التلقائي، وإعادة ترتيب المحطات وحذفها ومشاركة قائمتها.
- رسم المسار على الخريطة وترقيم محطاته. الخطوط مباشرة بين النقاط، وليست توجيهًا عبر طرق اللعبة. الحد 300 محطة.
- مشاركة رابط عميق للموقع بصيغة m8tpgta://marker?id=…؛ يعمل على جهاز لديه التطبيق ونفس قاعدة البيانات.
- تغيير مظهر صورة الخريطة: Satellite / Night contrast / High contrast. هذه معالجات لنفس الصورة، وليست الأنواع الستة الأصلية في GTAWeb.
- صفحة يومية وموسمية مع عداد لإعادة ضبط إنجاز الأقسام اليومية عند 06:00 UTC. يتم التحقق من تاريخ صلاحية أي feed قبل عرضه كتحديث حالي.
- استيراد JSON وصورة خريطة، تصدير/استعادة نسخة احتياطية تشمل المسار والمفضلة والتقدم، واسم ملف شخصي محلي.
- إعداد Codemagic وGitHub Actions لبناء IPA لجهاز آيفون، ثم تشغيل نسخة محاكاة والتحقق من تحميل الخريطة والبيانات وإنتاج صورة للواجهة.

## ما لم يكتمل من مطابقة GTAWeb

هذه النسخة **ليست مطابقة 100% للموقع**. التفاصيل الدقيقة في Docs/FEATURE-PARITY.md. لم تتوفر بيانات GTAWeb الكاملة للتنزيل المباشر؛ طلبات ملفات الموقع أعادت HTTP 403 بينما كانت صفحة الويب قابلة للفحص في المتصفح.

لا توجد إحداثيات قرع مفترضة في المشروع. الأقسام التي لا تتوفر لها بيانات، مثل Jack O’ Lanterns، تعرض Location data needed. كما لا يوجد مصدر متصل لتحديث Gun Van أو Street Dealers وغيرها تلقائيًا. لا توجد مزامنة لحساب GTAWeb، أو خريطة Cayo Perico، أو الطقس الحي، أو الأنواع الستة الأصلية للخريطة. عداد إعادة الضبط لا يعني وجود بيانات يومية حية.

## الحفاظ على نقاط الإصدار الأول

عند تحديث التطبيق بنفس Bundle ID وطريقة التوقيع، إذا كانت البيانات الحالية هي الكتالوج الفارغ في v1، يتم حفظ حالته الأصلية ثم تثبيت البيانات الجديدة. يمكن استرجاع النقاط عبر Data → Restore v1 pins on their original map. لم يتم نقلها إلى إحداثيات الخريطة الجديدة لأنها تستخدم امتدادًا مختلفًا. البيانات المستوردة الأخرى لا تُستبدل تلقائيًا.

صدّر Backup قبل تبديل قواعد البيانات. إلغاء تثبيت التطبيق قد يحذف الملفات المحلية. عند العودة إلى خريطة v1، يمكن الرجوع إلى بيانات v2 عبر Data → Install bundled community locations.

## البناء عبر Codemagic

1. فك ZIP وارفع محتويات مجلد M8TP-GTA-Map إلى جذر مستودع GitHub، أو استبدل ملفات المستودع السابق بالنسخة الجديدة كاملة. يجب أن يظهر codemagic.yaml ومجلد M8TPGTAMap.xcodeproj مباشرة في الجذر.
2. افتح https://codemagic.io واربط المستودع بحسابك الشخصي.
3. استخدم codemagic.yaml واختر workflow باسم ios-unsigned.
4. شغّل Start new build.
5. بعد نجاح الخطوات، نزّل M8TP-GTA-Map-unsigned.ipa من Artifacts. تتوفر أيضًا M8TP-GTA-Map-preview.png وهي لقطة فعلية من المحاكي، وsmoke-ready.json للتحقق من تحميل 933 موقعًا والخريطة.

مسار البناء لا يحتاج Apple ID أو شهادة في الخدمة لأنه ينتج IPA غير موقع. يُوقّع لاحقًا عبر SideStore أو AltStore Classic. لا يُثبت من تطبيق الملفات مباشرة.

Codemagic يوفّر بناءً باستخدام Xcode على macOS، وليس واجهة Xcode تفاعلية في المتصفح. راجع الخطة المجانية الحالية في https://docs.codemagic.io/billing/pricing/ قبل تشغيل البناء. إعداد الحساب الشخصي المرفق يستخدم macOS M2.

## GitHub Actions

تأكد من رفع المجلد المخفي .github ثم افتح Actions → Build iPhone IPA → Run workflow. المستودعات العامة تستخدم standard macOS runner وفق خطة GitHub الحالية. نزّل Artifact وفكّه بعد نجاح البناء وفحص المحاكي.

## التحقق الفعلي

اجتازت هذه النسخة فحوص بنية مشروع Xcode ومراجع الملفات والأصول وJSON وplist وYAML وShell وصياغة Swift. **لم تُجمع هذه النسخة المعدلة باستخدام Xcode ولم تُشغّل على جهاز أو محاكي في بيئة الإعداد.** صورة المستخدم تخص الإصدار السابق ولا تثبت عمل التعديلات الجديدة. البناء السحابي المرفق ينفذ اختبارات نموذج البيانات والمسار وحدّ إعادة الضبط اليومي، وتجميع iOS، وفحص منصة IPA، وتشغيل المحاكي والتقاط الواجهة. اختبار فتح القوائم والتعامل مع اللمس والصور وإعادة تشغيل التطبيق على الآيفون ما زال مطلوبًا بعد ذلك.

إذا فشل البناء، أرسل أول خطأ في خطوة البناء أو فحص المحاكي. لا تعتمد على ملف نتج من عملية فاشلة.

## إضافة البيانات الناقصة

اقرأ Docs/DATA-FORMAT.md. يجب أن تطابق البيانات نظام الصورة. للقاعدة الجديدة: x = lng / 8192 وy = -lat / 8192 فقط عندما تكون إحداثيات المصدر في امتداد صورة المجتمع نفسه؛ ليست هذه صيغة تحويل عامة من إحداثيات GTA ثلاثية الأبعاد. الصور المستوردة يجب أن تحافظ على نفس الامتداد الجغرافي.

يمكن استيراد ملف محلي أو ربط feed HTTPS متوافق يحتوي نفس dataset ID وmap ID وطابع validUntil مستقبلي. لا يوجد endpoint افتراضي غير موثق، ولا يتم الادعاء بأن بيانات ثابتة هي تحديث اليوم.
